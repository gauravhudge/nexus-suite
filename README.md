# Nexus Suite

A multi-tenant business suite (CRM + HRMS + ERP-lite) with an AI assistant, built step by step as a portfolio project.

**Status:** in progress. See [docs/PROGRESS.md](docs/PROGRESS.md) and [docs/LOGBOOK.md](docs/LOGBOOK.md).

## Planned stack
- Frontend: Angular
- Backend: Java, Spring Boot
- Database: PostgreSQL (Docker)
- AI: Claude API
- CI: GitHub Actions

## Modules (roadmap)
1. Auth, roles, organizations
2. CRM: leads, contacts, deals kanban
3. HRMS: employees, attendance, leave
4. ERP-lite: products, stock, invoices
5. AI assistant
6. Dashboards, deployment, Android app (Capacitor)
